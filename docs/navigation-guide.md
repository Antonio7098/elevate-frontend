# Navigation Guide - Settings & Profile Access

## Overview

The Settings and Profile pages are now easily accessible from the main sidebar navigation in the Elevate application. This guide explains how to access these pages and what features they provide.

## Sidebar Navigation

### Main Sidebar (Left Sidebar)

The main sidebar contains navigation to all major sections of the application, including:

#### Bottom Navigation Section
- **Profile** - Access your personal profile and learning statistics
- **Settings** - Configure your learning preferences and account settings

#### How to Access
1. Look for the **bottom section** of the left sidebar
2. You'll see two navigation items:
   - **Profile** (👤 icon) - Click to view/edit your profile
   - **Settings** (⚙️ icon) - Click to access all settings

### User Profile Area

Additionally, you can access your profile by clicking on your **username** in the bottom-right area of the sidebar.

## Page Descriptions

### Profile Page (`/profile`)

The Profile page provides a comprehensive view of your learning journey:

#### Features
- **Profile Header**: Avatar, name, email, member since date
- **Learning Statistics**: Study time, concepts mastered, mastery scores
- **Personal Information**: Editable name and contact details
- **Learning Preferences**: Daily goals, cognitive approach, explanation style
- **Account Security**: Password management, 2FA options

#### Navigation
- **URL**: `/profile`
- **Sidebar**: Click "Profile" in bottom navigation
- **Breadcrumb**: Shows "Profile" for context

### Settings Page (`/settings`)

The Settings page offers granular control over your learning experience:

#### Tabbed Interface
1. **Profile Tab**: Personal info and password changes
2. **Learning Tab**: Cognitive approach and explanation styles
3. **Study Tab**: Study configuration and tracking intensity
4. **Notifications Tab**: Communication preferences
5. **Billing Tab**: Subscription and payment information
6. **Privacy Tab**: Data sharing and privacy controls
7. **Data Tab**: Export functionality and account management

#### Navigation
- **URL**: `/settings`
- **Sidebar**: Click "Settings" in bottom navigation
- **Breadcrumb**: Shows "Settings" for context

## Mobile Navigation

### Responsive Design

On mobile devices, the sidebar navigation adapts:

- **Desktop**: Full sidebar with all navigation items visible
- **Tablet**: Collapsible sidebar with hover states
- **Mobile**: Horizontal tab navigation for settings

### Mobile Access

1. **Profile**: Accessible via the main navigation menu
2. **Settings**: Tabbed interface optimized for mobile screens
3. **Touch Friendly**: Optimized for touch interactions

## Quick Access Tips

### Keyboard Shortcuts

- **Profile**: Navigate to `/profile` directly
- **Settings**: Navigate to `/settings` directly

### Bookmarking

You can bookmark these pages for quick access:
- `https://yourdomain.com/profile`
- `https://yourdomain.com/settings`

### Direct Links

From any page in the application, you can:
1. Type the URL directly in the address bar
2. Use browser bookmarks
3. Navigate through the sidebar

## Navigation Flow

3. **Navigate to Settings** to customize preferences
4. **Configure Learning** approach and study habits
5. **Set Notifications** for reminders and updates

### Context Switching

- **From Dashboard**: Use sidebar navigation
- **From Learning Pages**: Quick access via sidebar
- **From Any Page**: Consistent navigation available

## Troubleshooting

### Common Issues

#### Can't See the Sidebar?
- Ensure you're logged in
- Check if the sidebar is collapsed (hover to expand)
- Verify you're on an authenticated page

#### Navigation Not Working?
- Check if you're logged in
- Verify the page routes are accessible
- Clear browser cache if needed

#### Mobile Navigation Issues?
- Ensure responsive design is working
- Check if JavaScript is enabled
- Try refreshing the page

### Getting Help

If you encounter navigation issues:

1. **Check Browser Console** for error messages
2. **Verify Login Status** in the top-right corner
3. **Try Different Browser** to isolate the issue
4. **Contact Support** with specific error details
